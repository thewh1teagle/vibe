# Заметки по установке 📝

## Системные требования

Windows: версия `8` или новее.

macOS: версия `13.3` или новее.

Linux: протестировано на `ubuntu-22.04+`

Оборудование:
Особых требований нет. Использование ресурсов можно настроить в расширенных настройках главного окна.

В настоящее время прослушивание аудиофайла не поддерживается в `Linux`

Кроме того, перед запуском может понадобиться задать эту переменную окружения

```console
export WEBKIT_DISABLE_COMPOSITING_MODE=1
```

## Настройка суммаризации с помощью Ollama

1. Установите Ollama

Скачайте и установите Ollama с https://ollama.com.

2. Установите модель

После установки настройте модель для суммаризации. Например, вы можете установить `llama3.1`, выполнив следующую команду в терминале:

```console
ollama run llama3.1
```

3. Включите суммаризацию

После установки модели откройте приложение Ollama. Перейдите в `Больше настроек` и включите суммаризацию непосредственно перед этапом транскрипции. Настройки можно оставить по умолчанию.

_Обязательно запустите «Запустить проверку», чтобы убедиться, что всё работает_

Вот и всё! Суммаризация теперь активна в Ollama.

## Стабильные метки времени (субтитры / фильмы)

Vibe включает режим стабильных меток времени для более точной синхронизации субтитров на длинном контенте.

1. Откройте `Больше настроек`.
2. Включите `Стабильные метки времени`.
3. При необходимости скачайте модель VAD.

Примечания:

- Этот режим ориентирован на качество и обычно примерно в `4x` медленнее обычной транскрипции.
- Лучше всего подходит для создания субтитров и синхронизации транскрипта фильмов/видео.
- Модель VAD, используемая по умолчанию: `ggml-silero-v6.2.0.bin`
- Исходный источник модели: `https://huggingface.co/ggml-org/whisper-vad`

## Перевод на английский

Перевод на английский работает только с моделями Whisper `small`, `medium` и `large`. С `large-v3-turbo` он не работает.

Если вам нужен перевод, скачайте поддерживаемую модель из [документации по моделям](/vibe/docs#models).

## Ручная установка 🛠️

`MacOS Apple silicon`: установите файл `aarch64.dmg` из [релизов](https://github.com/thewh1teagle/vibe/releases) **Не забудьте один раз открыть через правый клик → «Открыть» из папки «Программы»**

`MacOS Intel`: установите файл `x64.dmg` из [релизов](https://github.com/thewh1teagle/vibe/releases) **Не забудьте один раз открыть через правый клик → «Открыть» из папки «Программы»**

`Windows`: установите файл `.exe` из [релизов](https://github.com/thewh1teagle/vibe/releases)

`Linux`: установите `.deb` из [релизов](https://github.com/thewh1teagle/vibe/releases) (пользователи `Arch` могут воспользоваться [debtap](https://aur.archlinux.org/packages/debtap))

_Все модели доступны для ручной установки, см. [готовые модели](https://github.com/thewh1teagle/vibe/releases/tag/v0.0.1)_

## Автономная установка 💾

Автономная установка Vibe проста: откройте приложение, отмените загрузку и перейдите в раздел `Настроить` в настройках.

_Все модели доступны для ручной установки, см. настройки или [готовые модели](https://github.com/thewh1teagle/vibe/releases/tag/v0.0.1)_

## Более быстрая транскрипция на macOS (2-3x) 🌟

1. Скачайте подходящий файл `.mlcmodelc.zip` для своей модели с https://huggingface.co/ggerganov/whisper.cpp/tree/main

- например, `ggml-medium-encoder.mlmodelc.zip` соответствует `ggml-medium-encoder.bin`

2. Откройте папку с моделями в настройках Vibe
3. Перетащите файл `.mlcmodel.c` в папку моделей, чтобы он оказался рядом с файлом `.bin`
4. Транскрибируйте файл — при первом использовании модели это займёт больше времени, так как модель компилируется. Каждый следующий раз будет быстрее.

## Ошибка «`msvc140.dll` не найден» ❌

Скачайте и установите [vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)

## Специальная ссылка для скачивания моделей в vibe

Вы можете добавить на свой сайт ссылки, позволяющие пользователям скачивать ваши модели прямо с сайта в vibe.

URL должен выглядеть так

```
vibe://download/?url=https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny.bin?download=true
```

## Использование на linux-сервере

Чтобы использовать Vibe на linux-сервере, нужно установить виртуальный дисплей

```console
sudo apt-get install xvfb -y
Xvfb :1 -screen 0 1024x768x24 &
export DISPLAY=1

wget https://github.com/thewh1teagle/vibe/releases/download/v0.0.1/ggml-medium.bin
wget https://github.com/thewh1teagle/vibe/raw/main/server/fixtures/single.wav
vibe --model ggml-medium.bin --file single.wav
```
