## New

- 🧮 **CPU instruction set** — Settings → Advanced → Processor lets you pick Automatic, AVX2, or Baseline (AVX) for the engine's CPU build. Automatic follows what the processor supports; Baseline is the one to pick if transcription ever dies with an illegal instruction

## Fixed

- 💥 **Illegal instruction on older Intel Macs** — the Intel macOS engine was compiled for the CPU of the machine that built it, so an Intel Mac older than Haswell (2013) crashed the moment the model loaded. Intel macOS now ships the same two CPU builds as Linux and Windows and picks the right one at startup. Should the pick ever be wrong, Vibe relaunches the engine on the baseline build by itself and remembers that. Thanks to @I-G-1-1 for the report and the sysctl output (#1499)
- 🔍 **AVX2 line in bug reports** — on Intel Macs it was always `true`; it is a real check now
