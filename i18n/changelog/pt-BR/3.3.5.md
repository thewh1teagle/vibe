## Fixed

- 🔊 **Reprodução de áudio no Linux** — o botão de reproduzir não fazia nada no Linux, então não era possível ouvir uma gravação enquanto se revisava a transcrição. Os pacotes para Linux agora incluem o que o reprodutor de mídia do sistema precisa para abrir o arquivo (#1711)
- 📦 **Instalação no Fedora** — depois de instalar o RPM, o Vibe podia não abrir, com um erro de `libxdo.so.3` ausente. O pacote agora pede ao sistema que instale essa biblioteca junto com ele (#1124)
