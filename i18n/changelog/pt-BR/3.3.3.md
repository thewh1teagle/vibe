## New

- 🧭 **Obter modelos** — `Configurações → Modelos` tem uma nova página Obter modelos. Escolha o idioma das suas gravações, veja primeiro o modelo recomendado e instale qualquer modelo com um clique: o download é verificado, e o modelo fica pronto para usar assim que termina. Cada modelo mostra quem o criou
- ⚡ **Zipformer2 66M Hebrew** — um novo modelo de hebraico pequeno e muito rápido, de 75 MB. No nosso teste, ele transcreveu uma hora de hebraico em cerca de 30 segundos e usa bem menos memória que os modelos maiores. Ideal para áudio somente em hebraico
- 🌐 **Modelos no site** — a mesma lista agora é uma página no site, com um link para abrir qualquer modelo direto no Vibe: https://thewh1teagle.github.io/vibe/models
