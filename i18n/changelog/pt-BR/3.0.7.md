## New

- 📁 Suporte para arquivos de áudio muito maiores (até 15GB, antes era 1GB)
- 🔄 Carregamento de modelo mais confiável, com nova tentativa automática em caso de instabilidades de conexão
- 🔒 Opção para desativar a análise anônima nas Configurações

## Improved

- 🐧 Melhorada a detecção do binário do sona no Linux (Arch, CachyOS, instalações via AUR)

## Fixed

- 🛡️ Mensagem de erro clara quando nenhum modelo está selecionado, em vez de uma falha críptica
- 🔍 Diagnósticos de erro melhorados para resolver problemas mais rápido
