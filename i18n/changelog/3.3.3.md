## New

- 🧭 **Get models** — `Settings → Models` has a new Get models page. Choose the language of your recordings, see the recommended model first, and install any model with one click: the download is verified, and the model is ready to use as soon as it finishes. Each model shows who made it
- ⚡ **Zipformer2 66M Hebrew** — a new small and very fast Hebrew model, 75 MB. It transcribed an hour of Hebrew in about 30 seconds in our test and uses far less memory than the larger models. Best for Hebrew-only audio
- 🌐 **Models on the website** — the same list is now a page on the website, with a link to open any model straight in Vibe: https://thewh1teagle.github.io/vibe/models

## Fixed

- 🧩 **Sentences running together** — the plain-text result from Parakeet and Nemotron joined sentences without a space between them
