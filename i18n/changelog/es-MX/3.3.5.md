## Fixed

- 🔊 **Reproducción de audio en Linux** — el botón de reproducir no hacía nada en Linux, así que no se podía escuchar una grabación mientras se revisaba su transcripción. Los paquetes para Linux ahora incluyen lo que el reproductor multimedia del sistema necesita para abrir el archivo (#1711)
- 📦 **Instalación en Fedora** — después de instalar el RPM, Vibe podía fallar al iniciar con un error de `libxdo.so.3` faltante. Ahora el paquete le pide al sistema que instale esa biblioteca junto con él (#1124)
