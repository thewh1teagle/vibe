## New

- 📁 Soporte para archivos de audio mucho más grandes (hasta 15GB, antes 1GB)
- 🔄 Carga de modelo más confiable con reintento automático ante fallos de conexión
- 🔒 Opción para deshabilitar la analítica anónima en Configuración

## Improved

- 🐧 Mejor detección del binario de sona en Linux (instalaciones de Arch, CachyOS, AUR)

## Fixed

- 🛡️ Mensaje de error claro cuando no hay modelo seleccionado en lugar de una falla críptica
- 🔍 Se mejoraron los diagnósticos de error para resolver problemas más rápido
