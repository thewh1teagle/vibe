## New

- 🧭 **Obtener modelos** — `Configuración → Modelos` tiene una nueva página Obtener modelos. Elige el idioma de tus grabaciones, ve primero el modelo recomendado e instala cualquier modelo con un clic: la descarga se verifica y el modelo queda listo para usarse en cuanto termina. Cada modelo muestra quién lo creó
- ⚡ **Zipformer2 66M Hebrew** — un nuevo modelo de hebreo pequeño y muy rápido, de 75 MB. En nuestra prueba transcribió una hora de hebreo en unos 30 segundos y usa mucha menos memoria que los modelos más grandes. Ideal para audio solo en hebreo
- 🌐 **Modelos en el sitio web** — la misma lista ahora es una página del sitio web, con un enlace para abrir cualquier modelo directamente en Vibe: https://thewh1teagle.github.io/vibe/models
