## New

- 🧠 Přidali jsme pokročilé nastavení pro automatické uvolnění neaktivních přepisovacích modelů a uvolnění RAM/VRAM; nastavením na 0 zůstanou modely stále načtené
- ⏱️ Ochránili jsme aktivní nahrávání, VAD, diarizaci a dlouhé přepisy před uvolněním kvůli nečinnosti — časovač začíná běžet až po dokončení zpracování
- 🌍 Přidali jsme překlady nastavení nečinnosti modelu do všech podporovaných jazyků

## Improved

- ⚡ Vylepšili jsme opětovné použití modelu, takže Sona přeskočí opětovné načítání už načteného shodného modelu
- 🔄 Aktualizovali jsme Sona na v0.3.5 se sledováním nadřazeného procesu na Windows a spolehlivým úklidem podřízených procesů

## Fixed

- 🪟 Opravili jsme, že Vibe a Sona zůstávaly po ukončení na Windows spuštěné, což mohlo zabírat paměť GPU a bránit opětovnému spuštění
