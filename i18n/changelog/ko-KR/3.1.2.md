## New

- 🖥️ **AVX2가 없는 CPU에 이름이 붙음** — 이유 없이 죽는 대신, Vibe가 프로세서가 지원되지 않는다고, 그리고 왜 그런지 알려줍니다
- 🎙️ **녹음이 9dB 더 커짐** — 시스템 오디오를 믹싱하면 레벨이 슬며시 절반으로, 다시 절반으로 줄어들고 있었습니다. 시스템 오디오를 선택해 만든 모든 녹음이 원래보다 훨씬 작은 소리였습니다
- ⌨️ **받아쓰기 기본 단축키가 두 키로 변경** — macOS에서는 Option+Space, 그 외에서는 Ctrl+Space로, 기존의 세 키 조합 대신 사용됩니다
- 🤖 **에이전트 스킬 설치** — `설정 → API 및 에이전트`에서 Claude Code와 Codex에 스킬을 기록하여 모든 세션에서 사용할 수 있게 하며, 트랜스크립트 폴더와 로컬 API도 함께 내장됩니다
- 🪟 **Windows: VC++ 런타임 버전을 확인함** — 설치 프로그램은 *어떤* 런타임이든 있는지만 확인했기 때문에, 오래된 런타임이 설치된 기기는 그냥 통과되었다가 나중에 아무 메시지 없이 크래시했습니다

## Improved

- ⚙️ **설정이 다시 유지됩니다** — 3.1.1에서는 재시작할 때마다 모든 설정이 기본값으로 되돌아갔습니다. 디스크에 저장된 파일은 항상 올바랐지만, 앱이 이를 다시 읽어오지 않았을 뿐입니다. 설정을 다시 맞추는 것을 포기했더라도, 이제는 안전합니다
- 🧠 **모델 로드에 필요한 메모리가 절반으로** — 작은 모델에서 294MB에서 216MB로 측정되었고, 큰 모델에서는 모델 사본 하나 분량 정도가 줄었습니다. 로드 도중 메모리가 부족해지던 기기에도 이제 여유가 생겼습니다

## Fixed

- 🔍 **실패 이유가 표시됨** — 사이드카가 죽으면 이제 단순한 "sona process died" 대신 종료 코드와 시그널을 알려주며, 트랜스크립션 도중 크래시는 "error decoding response body"가 아니라 실제 크래시로 표시됩니다. Whisper 자체의 진단 정보도 아무 동작도 하지 않던 콜백에 의해 조용히 버려지던 문제가 해결되어 다시 로그에 도달합니다
- 📦 **손상된 모델 다운로드를 감지함** — 파일은 사용되기 전에 검증되며, 불완전한 파일은 시작 시 감지되어 재다운로드를 제안받고, 중단된 다운로드가 설치된 모델인 척할 수 없게 되었습니다
- 📱 **휴대폰 페어링 QR코드가 스캔됨** — QR 생성기의 잘못된 문자 하나가 특정 크기 이상의 코드에서 정렬 패턴을 잘못된 위치에 두었는데, 페어링 코드가 딱 그 크기를 넘었습니다. 어떤 스캐너도 읽을 수 없었습니다
- 🔗 **yt-dlp가 더 이상 성가시게 하지 않음** — 업데이트 알림이 매번 실행할 때마다 나타나며 "Later"를 선택해도 매번 잊어버렸습니다. 이제 일주일에 최대 한 번만 닫을 수 있는 토스트로 표시되며, 실제로 다운로드가 실패했을 때, 즉 도움이 될 때 업데이트를 제안합니다
- 🌍 22개 언어 전체에서 제품명과 잘못 번역된 설정 항목을 수정했습니다
