## New

- ⚡ **Zipformer2 66M Slovak** — @neurlang 님이 만든 작고 매우 빠른 새 슬로바키아어 모델로, 크기는 75 MB입니다. `설정 → 모델`에서 모델 받기를 열고 슬로바키아어를 선택해 설치하세요. 슬로바키아어만 나오는 오디오에 가장 적합합니다

## Fixed

- 🧱 **AVX가 없는 프로세서** — 오래된 Pentium, Celeron 칩처럼 AVX가 없는 프로세서에서 잘못된 명령어 오류로 받아쓰기가 멈추던 문제를 고쳤습니다. 이제 Vibe에 해당 프로세서용 빌드가 포함되어 있으며 자동으로 선택됩니다. 이런 프로세서에서는 속도가 느릴 수 있으니, 작은 모델을 쓰는 것이 가장 좋습니다 (#1731)
- 🪜 **자동 단계 내리기** — 받아쓰기 엔진이 프로세서가 실행할 수 없는 명령어에서 멈추면, 이제 Vibe가 동작하는 빌드를 찾을 때까지 한 단계 더 단순한 빌드로 다시 시도하고 그 결과를 기억합니다. `설정 → 고급`에 직접 지정할 수 있는 SSE4.2 선택지가 새로 생겼습니다
