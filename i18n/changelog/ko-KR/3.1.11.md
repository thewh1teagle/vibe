## New

- 📤 **자동 내보내기** — 설정 → 트랜스크립션에서 한 번만 켜두면 모든 트랜스크립트가 완료되는 즉시 원하는 형식(VTT, SRT, text, Markdown, JSON, CSV, DOCX, PDF, HTML)으로, 각 녹음 옆에, 프로젝트 폴더에, 또는 직접 지정한 폴더 하나에 저장됩니다. 기존 파일은 교체를 요청하지 않는 한 그대로 유지되고, 쓸 수 없는 녹음 폴더는 프로젝트 폴더로 대체됩니다. 예전 배치 페이지가 하던 일이 앱 전체에 돌아온 것입니다
- 🏁 **배치의 순간** — 여러 파일을 트랜스크립션할 때 진행 상황과 예상 소요 시간이 표시되며, 완료되면 몇 개가 내보내졌는지, 건너뛰었는지, 실패했는지 알려주는 카드가 Open folder 버튼과 함께 뜨고, 배치 전체에 대해 데스크톱 알림이 하나 표시됩니다. 목록의 각 파일은 무엇을 생성했는지 표시합니다
- 🧭 **배치 내 내보내기 메뉴** — Export 버튼이 메뉴로 바뀌어 Export this transcript, 자동 내보내기가 켜지기 전에 완료된 항목을 위한 Export all finished, 그리고 자동 내보내기 설정을 제공합니다. 제보해 준 @LivingInternet에게 감사드립니다 (#1480)

## Improved

- 🌓 **테마 전환** — 드롭다운 대신 설정에 해와 달 아이콘으로 표시됩니다
- 🗂️ **모든 오디오 트랙이 인식됨** — 여러 오디오 트랙(OBS, Discord, 화자별 트랙 등)이 있는 녹음은 이전에는 트랙 하나만 트랜스크립션되었는데, 이제 나머지도 함께 믹싱되어 모든 화자가 나타나며 엔진이 원래 들을 필요가 없던 무음 구간에서 같은 문장을 반복하는 일도 사라졌습니다

## Fixed

- 🔁 **몇 분씩 반복되던 문장** — 위 변경으로, 모델이 끊긴 트랙에서 무음을 들으며 화자는 계속 말하고 있었던 다중 트랙 녹음에서 발생하던 반복 루프가 사라졌습니다 (#1518, #1505)
