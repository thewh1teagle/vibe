## New

- 🧭 **모델 받기** — `설정 → 모델`에 새로운 모델 받기 페이지가 생겼습니다. 녹음 언어를 선택하면 추천 모델이 가장 먼저 표시되고, 클릭 한 번으로 어떤 모델이든 설치할 수 있습니다. 다운로드가 검증되며, 끝나는 즉시 모델을 사용할 수 있습니다. 각 모델에는 만든 곳이 표시됩니다
- ⚡ **Zipformer2 66M Hebrew** — 작고 매우 빠른 새 히브리어 모델로, 크기는 75MB입니다. 테스트에서 1시간 분량의 히브리어를 약 30초 만에 받아썼고, 더 큰 모델보다 메모리를 훨씬 적게 씁니다. 히브리어만 나오는 오디오에 가장 적합합니다
- 🌐 **웹사이트의 모델 목록** — 같은 목록이 이제 웹사이트의 페이지로도 제공되며, 어떤 모델이든 Vibe에서 바로 여는 링크가 있습니다: https://thewh1teagle.github.io/vibe/models

## Fixed

- 🧩 **붙어 버리던 문장** — Parakeet과 Nemotron의 일반 텍스트 결과에서 문장 사이에 공백 없이 이어지던 문제를 고쳤습니다
