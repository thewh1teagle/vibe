## New

- 🧪 **베타 업데이트** — 설정 → 일반 → 베타 업데이트를 켜면 다른 사용자보다 며칠 먼저 새 버전을 받으므로, 대부분의 사용자에게 도달하기 전에 문제를 발견할 수 있습니다. 켜면 즉시 업데이트를 확인하며, 끄면 안정 버전이 따라잡을 때까지 현재 버전이 유지됩니다 (#1677)

## Improved

- 📶 **업데이트 진행률** — 업데이트 대화상자의 진행 막대가 튀지 않고 꾸준히 움직이며, 대화상자가 닫힐 때 다시 비어 버리지 않습니다
- 🇮🇱 **모델 문서의 히브리어 Parakeet** — Models 페이지에 히브리어 Parakeet TDT 모델이 추가되었습니다 (#1624)
