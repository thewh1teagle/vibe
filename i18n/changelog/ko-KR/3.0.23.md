## New

- 🧠 비활성 트랜스크립션 모델을 자동으로 언로드하여 RAM/VRAM을 확보하는 고급 설정을 추가했습니다. 0으로 설정하면 모델이 계속 로드된 상태로 유지됩니다
- ⏱️ 진행 중인 업로드, VAD, 화자 분리, 긴 트랜스크립션을 유휴 언로드로부터 보호합니다 — 타임아웃은 처리가 끝난 후에만 시작됩니다
- 🌍 모델 비활성 설정에 대한 번역을 지원하는 모든 언어에 추가했습니다

## Improved

- ⚡ 모델 재사용을 개선하여 Sona가 이미 로드된 동일한 모델을 다시 로드하지 않도록 했습니다
- 🔄 Windows 부모 프로세스 모니터링과 안정적인 자식 프로세스 정리 기능을 포함한 Sona v0.3.5로 업데이트했습니다

## Fixed

- 🪟 종료 후에도 Vibe와 Sona가 Windows에서 계속 실행되어 GPU 메모리를 점유하고 재실행을 막던 문제를 수정했습니다
