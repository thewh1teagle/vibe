## Improved

- 🔒 **더 안전한 다운로드** — 카탈로그의 모델과 yt-dlp 도우미는 사용하기 전에 공개된 체크섬으로 검증하며, 모델 다운로드는 HTTPS로만 진행됩니다. 카탈로그에 없는 모델로 연결되는 `vibe://download` 링크는 경고와 함께 전체 주소를 보여 주고, 더 이상 자동으로 선택되지 않습니다 (#1741)
- 🧹 **임시 파일** — 진행 중인 녹음과 다운로드는 공용 시스템 임시 폴더 대신 Vibe 전용 비공개 폴더에 저장되고, 프로젝트에 저장되는 즉시 삭제되며, 남은 파일은 하루 뒤에 정리됩니다 (#1741, #841)
- 🕶️ **사용 통계** — 오류 보고서에 더 이상 파일 이름이나 폴더 경로가 포함되지 않으며, 사용 통계를 끄면 전송 대기 중이던 데이터도 모두 폐기됩니다. `DO_NOT_TRACK=1`을 설정해도 사용 통계가 꺼집니다 (#1741)
- 🎙️ **마이크 없음** — 선택한 마이크나 스피커의 연결이 끊어지면 Vibe가 시스템 기본 장치로 녹음하고 이를 알려 주며, 해당 장치가 다시 연결되면 선택한 장치로 돌아옵니다. 소리가 전혀 녹음되지 않은 경우에는 이제 경고가 표시됩니다 (#1676)

## Fixed

- 🐘 **매우 큰 파일** — 용량이 수 GB인 동영상을 받아쓰면 파일 전체가 메모리에 올라가 메모리 부족 오류로 비정상 종료될 수 있었습니다. 이제 파일을 디스크에서 필요한 만큼씩 읽습니다 (#1557)
- 📱 **iPhone과 Safari에서 휴대폰 녹음** — 모든 iPhone과 Safari에서 페어링 시간이 초과되었습니다. 이제 휴대폰 페이지가 제대로 연결되며, 이 문제는 데스크톱 업데이트가 필요하지 않습니다 (#1566)
- 🎚️ **엉뚱한 장치로 녹음** — 저장된 마이크가 장치 목록의 순서로 기억되어, 헤드폰이나 가상 오디오 장치를 연결한 뒤 Vibe가 모르는 사이에 다른 장치로 녹음하거나 "Failed to get device by ID" 오류와 함께 실패할 수 있었습니다 (#1676)
- 💥 **일부 Windows 그래픽 카드에서 비정상 종료** — 받아쓰는 도중 그래픽 드라이버 오류가 발생하면 "Rust cannot catch foreign exceptions" 메시지와 함께 엔진이 종료되었습니다. 이제 이런 오류를 처리하며, Vibe는 해당 파일을 CPU로 다시 시도합니다 (#1250)
- 🛑 **취소와 새 트랜스크립션** — 트랜스크립션 하나를 취소하면 실행 중이던 다른 작업까지 멈출 수 있었고, 새 트랜스크립션을 누르면 진행 중이던 작업이 버려졌습니다. 이제 취소하면 취소한 작업만 중지되고, 새 파일은 실행 중인 작업 뒤에 대기열로 들어갑니다 (#1484, #1477)
- 🎬 **Windows에서 "Access is denied"** — `ffmpeg`라는 폴더가 시스템 PATH에 있으면 모든 받아쓰기가 "invalid audio file: Access is denied" 오류로 실패했습니다. 이제 Vibe에 포함된 자체 ffmpeg를 먼저 사용합니다 (#1668)
- 🔗 **붙여넣은 링크** — 링크 입력란에 붙여넣은 텍스트가 웹 주소가 아니면 다운로더로 넘기지 않고 입력란에 그대로 남겨 둡니다 (#1741)
- 🖼️ **내보내기 미리보기** — 이제 미리보기가 JSON과 일반 텍스트를 포함한 모든 형식에서 밝게 또는 어둡게 선택을 따릅니다
