## New

- ✨ **AI 어시스턴트** — 설정 → AI 어시스턴트에서 연결(Ollama, OpenAI 호환, 또는 Claude)을 한 번만 설정하면, Test 버튼이 키와 서버가 작동하는지 한 줄로 알려줍니다. 요약과 받아쓰기 정리가 이제 각각 별도의 작업으로 분리되어 저마다 스위치, 프리셋, 프롬프트 페이지를 가지므로, 회의록 프롬프트를 조정해도 받아쓰기가 문장을 처리하는 방식은 바뀌지 않습니다
- 💬 **이 트랜스크립트에 대해 질문하기** — 요약 아래의 입력창이 트랜스크립트 자체를 바탕으로 질문("예산에 대해 어떻게 결정됐나요?")에 답하며, 답변이 실시간으로 흐르듯 표시되고, 대화 내용은 프로젝트에 저장되어 다음 달에도 그대로 남아 있습니다
- 🧩 **프롬프트 프리셋과 플레이스홀더** — Summary, Meeting notes, TL;DR, Translate, Rewrite as article 중에서 시작하고, 직접 작성하는 프롬프트에는 `{transcript}`, `{language}`, `{speakers}`를 사용할 수 있습니다. 받아쓰기에는 Punctuation only, Formal, Casual이 있고, 실제로 사용하기 전에 한 문장이 어떻게 바뀌는지 확인할 수 있는 Try it 입력창이 있습니다

## Improved

- 🌊 **요약이 실시간으로 흐름** — 모델이 텍스트를 작성하는 대로 화면에 나타나며, 요약이 시작되면 Summary 탭이 자동으로 열립니다
- 📚 **긴 녹음** — 모델의 컨텍스트에 담기에 너무 긴 트랜스크립트는 잘려나가는 대신 부분별로 요약된 뒤 전체로 다시 요약되며, 진행 상황을 부분 카운터로 보여줍니다
- 🎙️ **받아쓰기 정리** — 자체 프롬프트로 실행되며, 모델이 실패해도 원본 단어가 그대로 입력되거나 복사됩니다

## Fixed

- 🔁 **받아쓰기가 요약 프롬프트로 실행되던 문제** — 받아쓰기한 텍스트가 요약 프롬프트에 적힌 내용대로 처리되어 한 문장이 회의록으로 바뀌어 버리곤 했습니다. 이제 각 작업은 자신만의 프롬프트를 가집니다
- 🔑 **설정 이전** — 기존 AI 설정(키, 모델, 프롬프트)이 첫 실행 시 자동으로 이전되므로 다시 입력할 필요가 없습니다
