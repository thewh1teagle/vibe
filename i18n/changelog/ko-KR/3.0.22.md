## New

- 🎙️ Nemotron 3.5와 Parakeet TDT v3 모델 지원을 추가했으며, 받아쓰기용 스트리밍 트랜스크립션도 포함됩니다
- 🌍 데스크톱 앱과 웹사이트를 Paraglide i18n으로 이전하고 번역 테스트를 추가했습니다
- 🔄 앱 업데이트를 설치하기 전에 Sona를 깔끔하게 종료합니다

## Improved

- ⚡ Sona를 업데이트하여 트랜스크립션을 개선하고 사용 가능한 트랜스크립션 옵션을 명확히 했습니다
- ✨ 모델 선택 흐름을 개선했습니다
- 🎨 Wall of Love 디자인을 개선했습니다
- 🛠️ 웹사이트 배포와 타입 검사의 안정성을 개선했습니다

## Fixed

- 🪟 Windows 코드 서명을 선택 사항으로 만들고 빌드 설정을 수정했습니다
