## New

- 📱 휴대폰으로 녹음하세요: `설정 → 휴대폰`에서 QR코드를 한 번 스캔하면, 휴대폰이 녹음을 이 컴퓨터로 전송할 수 있습니다. 이미 로드된 모델로 트랜스크립션한 뒤 텍스트를 곧바로 다시 보내줍니다
- 🏠 휴대폰 쪽은 홈 화면에 추가하는 웹 앱입니다: 앱스토어에서 설치할 것도, 계정도 필요 없으며, 셀룰러에서도 wifi에서도 작동합니다
- 🔒 오디오는 [iroh](https://www.iroh.computer/) 기반의 암호화된 P2P 연결을 통해 전송됩니다. 휴대폰 브라우저는 홀 펀칭을 할 수 없으므로 오직 암호문만 보는 릴레이를 거쳐 전달되며, 오디오 원본은 결코 노출되지 않습니다
- 💾 휴대폰 녹음은 `Documents/Vibe`에 저장되며 다른 트랜스크립트와 마찬가지로 Recents에 표시됩니다. 녹음은 컴퓨터에 다시 연결될 때까지 휴대폰에 안전하게 대기합니다
- 🌍 휴대폰의 언어 선택 목록은 로드된 모델에서 가져오므로, 항상 데스크톱이 실제로 할 수 있는 것만 정확히 제공합니다
- 🚀 기본값이 꺼짐인 새로운 "시작 시 실행" 설정이 "트레이에서 계속 실행" 옆에 추가되었습니다. 두 설정을 함께 사용하면 휴대폰을 꺼내 들 때 데스크톱이 계속 연결되어 있습니다
- 🌐 새로 추가된 모든 화면이 22개 언어 전체로 번역되었습니다
