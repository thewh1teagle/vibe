## Fixed

- 🧩 **没有 Vulkan 运行时也没关系** — 没有安装 Vulkan 加载器（缺少 `vulkan-1.dll`，常见于未安装显卡驱动的机器）的 Windows 电脑此前根本无法启动转录引擎。引擎现在会在运行时尝试打开加载器，找不到就直接改用 CPU 运行。上游：ggml-org/ggml#1614
- 🎯 **老驱动的 AMD 显卡也能正确转录** — 在运行 2020 年前后 Windows 驱动的部分 AMD 显卡上（在一台 Ryzen 笔记本的 Radeon 核显上出现过），GPU 转录结果是乱码：孤零零的一个“!”或随机字符，而 CPU 转录是正确的。这是因为驱动在引擎中把该 GPU 归类为“未知”，导致注意力内核请求了硬件无法支持的子组宽度。Sona 0.6.5 只在驱动确实能提供该宽度时才请求它，GPU 又能正确转录了，速度也比 CPU 快好几倍。已向 ggml 上游提出修复方案 (ggml-org/ggml#1619)
