## New

- 🧠 新增“高级设置”中的一项：自动卸载闲置的转录模型以释放内存和显存；设为 0 即可让模型始终保持加载
- ⏱️ 正在进行的上传、语音活动检测（VAD）、发言者分离和长时间转录不会被闲置卸载打断——超时计时只会在处理结束后才开始
- 🌍 为所有支持的语言添加了模型闲置设置的翻译

## Improved

- ⚡ 改进了模型复用逻辑，如果匹配的模型已经加载，Sona 会跳过重新加载
- 🔄 将 Sona 更新到 v0.3.5，新增 Windows 父进程监控，并让子进程的清理更加可靠

## Fixed

- 🪟 修复了在 Windows 上退出后 Vibe 和 Sona 仍未完全关闭的问题，这会占用 GPU 显存并导致无法重新启动
