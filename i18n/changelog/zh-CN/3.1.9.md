## Improved

- 🔍 **错误信息会显示引擎打印的内容** — 当 Sona 在转录过程中意外退出时，错误对话框、日志和错误报告会带上它最后输出的内容，而不再只是一句“failed to read sona event line”，因此像上面这样的问题也能从报告中定位出来

## Fixed

- 🛠️ **老版本 AMD 显卡驱动也能转录了** — 自从换用新引擎后，搭载 2020 年前后 AMD 驱动（Vulkan 1.2，常见于 Ryzen 加 Radeon 显卡的笔记本）的机器在第一次提交 GPU 任务时就会崩溃，报错“vkQueueSubmit: Invalid queue”。原因是驱动的 `vkGetDeviceQueue2` 返回了空的队列句柄；Sona 0.6.4 改为回退使用 `vkGetDeviceQueue`，GPU 又能正常工作了。更新 AMD 驱动仍然是个好主意，但已经不再是必须的
- 🖥️ **老款 Intel 和 AMD CPU 也能用了** — Vibe 不再拒绝在没有 AVX2 的 CPU 上转录。Sona 提供两份 CPU 引擎：AVX2 版本和 AVX 基线版本，启动时会选择处理器能运行的那一份。2011 年以后的任何 x86-64 机器现在都能转录，“您的 CPU 不受支持”的提示已经消失
- 🎮 **显存不足不再中断转录** — 当显卡在处理某个文件时显存耗尽，Vibe 会把模型重新加载到 CPU 上，重试这个文件一次，并用 CPU 完成队列中剩余的文件。该模型会被记住“显存放不下”，此后自动改用 CPU 加载。感谢 @mikemikimike 提供报告并完成初版修复 (#1471, #1472)
