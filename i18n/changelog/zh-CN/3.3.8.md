## New

- 🦜 **更多 Parakeet 模型** — 现在可以加载任何 GGUF 格式的 Parakeet TDT 模型，不再只限于名称含 v3 的模型，因此其他发布者的微调模型也能使用。为不同音频格式构建的模型会被直接拒绝并给出明确提示，而不是稍后才失败。Orukeet 0.6B 是针对 25 种欧洲语言的 Parakeet v3 微调模型，可在 `获取模型` 中获取 (#1577, #1753) — 感谢 @Nathan-Roll1
- ⬇️ **后台下载更新** — 新版本现在会在你工作时悄悄下载，并等你需要时再安装。安装只需一键：Vibe 会更新、自动重启，并回到你离开时的位置，不会再询问第二次。除非你要求，否则绝不会安装或重启。你可以在 `设置 → 通用` 中关闭下载
- 🔔 **更新提醒** — 如果有更新已等待两天，应用内会显示一个小提示条，带有“稍后更新”和“重启并更新”。没有弹窗，也没有系统通知

## Improved

- 🔒 **更安全的下载** — 目录中的模型和 yt-dlp 辅助程序在使用前，会先对照已发布的校验和进行检查，并且模型下载只通过 HTTPS 进行。指向不在目录中的模型的 `vibe://download` 链接会显示完整地址并给出警告，也不再被自动选中 (#1741)
- 🧹 **临时文件** — 录音和正在进行的下载现在存放在 Vibe 自己的私有文件夹中，而不是共用的系统临时文件夹；保存到项目后会立即删除，残留的文件会在一天后清理 (#1741, #841)
- 🕶️ **匿名使用统计** — 错误报告不再包含文件名或文件夹路径，关闭匿名使用统计时，也会丢弃所有等待发送的内容。设置 `DO_NOT_TRACK=1` 同样会关闭统计 (#1741)
- 🎙️ **找不到麦克风** — 如果你选择的麦克风或扬声器被拔出，Vibe 会改用系统默认设备录音并提示你，设备重新接上后会恢复你的选择。完全没有录到声音的录音现在会显示警告 (#1676)

## Fixed

- 🎬 **无法转换的文件** — 当视频或音频文件无法读取时，错误信息显示的是 ffmpeg 的版本详情，而不是原因。现在会显示文件出了什么问题 (#1752)
- 🐘 **超大文件** — 转录数 GB 的视频时可能因内存不足而崩溃，因为整个文件都被载入了内存。现在文件会边处理边从磁盘读取 (#1557)
- 📱 **在 iPhone 和 Safari 上用手机录音** — 在每一台 iPhone 和 Safari 中，配对都会超时。现在手机页面可以正常连接；这一项不需要更新桌面端 (#1566)
- 🎚️ **从错误的设备录音** — 保存的麦克风是按它在设备列表中的位置记住的，因此插上耳机或虚拟音频设备后，Vibe 可能悄悄改用另一个设备录音，或因 "Failed to get device by ID" 而失败 (#1676)
- 💥 **部分 Windows 显卡上的崩溃** — 转录期间显卡驱动出错，会使引擎以 "Rust cannot catch foreign exceptions" 关闭。现在这些错误会被处理，Vibe 会改用 CPU 重试该文件 (#1250)
- 🛑 **取消与新建转录** — 取消一个转录可能会停止其他正在运行的转录，而点击“新建转录”会丢弃正在进行的那一个。现在“取消”只会停止你取消的任务，新文件会排在正在运行的任务之后 (#1484, #1477)
- 🎬 **Windows 上的 "Access is denied"** — 如果系统 PATH 中有一个名为 `ffmpeg` 的文件夹，每次转录都会失败，并提示 "invalid audio file: Access is denied"。现在 Vibe 会优先使用自带的 ffmpeg (#1668)
- 🔗 **粘贴的链接** — 粘贴到链接框中、但不是网址的文本会留在框里，而不会被传给下载器 (#1741)
- 🖼️ **导出预览** — 预览现在会在所有格式中跟随“浅色”或“深色”的选择，包括 JSON 和纯文本
- 🫥 **隐藏启动** — 当 Vibe 设置为开机启动时，它的窗口仍可能弹出并抢占焦点。现在它会一直留在托盘中，直到你打开它
