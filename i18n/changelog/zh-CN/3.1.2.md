## New

- 🖥️ **明确指出不支持 AVX2 的 CPU** — Vibe 不再默默崩溃，而是会说明处理器不受支持以及原因
- 🎙️ **录音音量提高了 9 dB** — 混入系统音频时，音量此前被悄悄减半了两次。只要开启了系统音频录制，录音的音量都远比应有的要小
- ⌨️ **听写默认快捷键改为两键组合** — macOS 上是 Option+Space，其他平台是 Ctrl+Space，不再是三键组合
- 🤖 **安装智能体技能** — `设置 → API 与智能体`中可以一键写入 Claude Code 和 Codex，让每个会话都能使用，并已内置转录文件夹和本地 API 信息
- 🪟 **Windows：VC++ 运行库会检查版本** — 安装程序此前只检测是否存在“某个”运行库，因此装有旧版本的机器会被跳过，之后无声无息地崩溃

## Improved

- ⚙️ **设置又能保存住了** — 在 3.1.1 中，每次重启所有设置都会恢复默认值。磁盘上的配置文件其实一直是对的，只是应用从未把它读回来。如果你已经放弃重新设置自己的偏好，现在可以放心了
- 🧠 **加载模型所需内存减半** — 实测一个小模型从 294 MB 降到 216 MB，大模型上大约省下一份完整模型副本的内存。此前加载到一半就内存不足的机器现在有了余量

## Fixed

- 🔍 **失败会说明原因** — sidecar 进程退出时现在会报告退出码和信号，而不再只是一句“sona process died”；转录过程中的崩溃也会如实显示为崩溃，而不是“error decoding response body”。Whisper 自身的诊断信息也重新出现在日志里，此前它们被一个空实现的回调悄悄丢弃了
- 📦 **损坏的模型下载会被检测出来** — 文件在使用前会先校验，启动时会检测出不完整的文件并提示重新下载，中断的下载也不会再被误认为是已安装的模型
- 📱 **手机配对二维码可以扫描了** — 二维码生成器中一个错误字符导致超过一定大小的二维码定位图案错位，而配对二维码恰好超过了这个大小，导致任何扫描器都无法识别
- 🔗 **yt-dlp 不再反复提醒** — 更新提示此前每次启动都会出现，点了“稍后”也不会被记住。现在改成最多每周一次、可关闭的提示条，并且只在下载真正失败时才提示更新，这才是它真正有用的时候
- 🌍 修正了全部 22 种语言中的产品名称和一处误译的设置项
