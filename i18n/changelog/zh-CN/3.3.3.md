## New

- 🧭 **获取模型** — `设置 → 模型` 中新增了“获取模型”页面。选择录音所用的语言，先看到推荐的模型，一键即可安装任何模型：下载会经过校验，完成后模型即可使用。每个模型都会标明出自谁手
- ⚡ **Zipformer2 66M Hebrew** — 全新的小巧且极快的希伯来语模型，仅 75 MB。在我们的测试中，它约 30 秒就转录完一小时的希伯来语音频，占用的内存也远少于较大的模型。最适合纯希伯来语音频
- 🌐 **网站上的模型** — 同一份列表现在也是网站上的一个页面，并提供链接，可直接在 Vibe 中打开任意模型：https://thewh1teagle.github.io/vibe/models

## Fixed

- 🧩 **句子连在一起** — Parakeet 和 Nemotron 输出的纯文本结果中，句子之间没有空格，连成了一片
