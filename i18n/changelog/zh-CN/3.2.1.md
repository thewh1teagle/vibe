## New

- 🧮 **CPU 指令集** — “设置 → 高级设置 → 处理器”中可以为引擎的 CPU 版本选择“自动”“AVX2”或“基线（AVX）”。自动会根据处理器实际支持的指令集选择；如果转录因非法指令而崩溃，就选基线

## Fixed

- 💥 **老款 Intel Mac 上的非法指令** — Intel macOS 引擎此前是针对构建它的那台机器的 CPU 编译的，因此早于 Haswell（2013 年）的 Intel Mac 一加载模型就会崩溃。Intel macOS 现在和 Linux、Windows 一样提供两种 CPU 版本，并在启动时自动选择合适的一个。如果选错了，Vibe 会自行改用基线版本重启引擎，并记住这个选择。感谢 @I-G-1-1 提供报告和 sysctl 输出 (#1499)
- 🔍 **错误报告中的 AVX2 一行** — 此前在 Intel Mac 上一律显示 `true`；现在是真正的检测结果
