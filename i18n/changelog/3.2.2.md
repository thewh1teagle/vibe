## New

- 📱 **Phones stay paired** — Settings → Phone lists every phone you have connected, with the name it gave and the date it paired. Each one holds its own credential, so revoking a phone you lost leaves the others connected. Revoke all is there when you would rather start over, and pairing returns you to the Phone page instead of leaving you on a code
- 🌍 **Release notes and docs in your language** — every release since 0.0.2, and the Install and Models pages, are translated into all 14 website languages. An entry nobody has translated yet stays English rather than mixing two languages in one paragraph
- 🆕 **What's new** — the version at the bottom of Settings opens the notes for the build you are running

## Improved

- 🧭 **Settings read better** — clearer section headings, and Whisper options, audio processing and phone pairing each get their own page instead of a dialog stacked on a dialog. Moving between sections is instant
- 🗣️ **The app itself is fully translated** — 123 strings that had fallen back to English in all 21 languages are filled in, from auto-export to the AI Assistant
- 🎬 **Dictation output** — clearer icons for where the text goes, and registering a shortcut now tells you whether it worked
- 🇮🇱 **Right-to-left pages** — Hebrew reads right to left throughout, while code blocks and file paths stay left to right where they belong

## Fixed

- ⌨️ **Stale shortcuts** — a global shortcut left registered by an earlier run is cleared at startup, so the key you press is the one that fires
- 🎙️ **Phone transcription** — Silero VAD resolves properly for recordings sent from a phone
- 🔢 **Decoder limits** — capped at eight in both the interface and the engine, so a high value can no longer stall a transcription
