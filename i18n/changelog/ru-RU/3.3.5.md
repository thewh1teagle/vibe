## Fixed

- 🔊 **Воспроизведение аудио в Linux** — кнопка воспроизведения в Linux ничего не делала, поэтому нельзя было слушать запись, проверяя расшифровку. Теперь пакеты для Linux включают всё, что нужно системному медиаплееру, чтобы открыть файл (#1711)
- 📦 **Установка в Fedora** — после установки RPM Vibe мог не запускаться из-за ошибки об отсутствующей `libxdo.so.3`. Теперь пакет просит систему установить эту библиотеку вместе с ним (#1124)
