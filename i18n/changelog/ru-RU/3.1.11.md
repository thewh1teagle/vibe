## New

- 📤 **Автоэкспорт** — включите один раз в Настройки → Транскрипция, и каждый транскрипт будет записываться сразу после завершения, в выбранных форматах (VTT, SRT, text, Markdown, JSON, CSV, DOCX, PDF, HTML), рядом с каждой записью, в папке проектов или в одной выбранной вами папке. Существующие файлы сохраняются, если не попросить их заменить, а если папку записи нельзя использовать для записи, файл уходит в папку проектов. Это возвращает то, что раньше умела старая страница пакетной обработки, но теперь для всего приложения
- 🏁 **Момент пакетной обработки** — при транскрипции нескольких файлов теперь показывается прогресс по всему запуску с оценкой времени, а в конце — карточка с тем, сколько файлов экспортировано, пропущено или завершилось ошибкой, с кнопкой Open folder, плюс одно уведомление на рабочем столе для всего пакета. Каждый файл в списке показывает, что он выдал на выходе
- 🧭 **Меню экспорта в пакетной обработке** — кнопка Export превращается в меню с пунктами Export this transcript, Export all finished (для всего, что было завершено до включения автоэкспорта) и настройкой автоэкспорта. Спасибо @LivingInternet за отчёт (#1480)

## Improved

- 🌓 **Переключатель темы** — солнце и луна в Settings вместо выпадающего списка
- 🗂️ **Слышна каждая аудиодорожка** — запись с несколькими аудиодорожками (OBS, Discord, по одной на каждого говорящего) раньше распознавалась только по одной дорожке; теперь остальные подмешиваются, поэтому виден каждый говорящий, и движок больше не повторяет строку поверх тишины, которую вообще не должен был слышать

## Fixed

- 🔁 **Повторяющееся предложение на несколько минут** — цикл, возникавший на многодорожечных записях, где модель слышала тишину на отключённой дорожке, пока говорящий продолжал говорить, исчез благодаря изменению выше (#1518, #1505)
