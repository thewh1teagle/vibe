## New

- 🧠 Добавлена настройка в Advanced для автоматической выгрузки неактивных моделей транскрипции и освобождения RAM/VRAM; значение 0 держит модели загруженными постоянно
- ⏱️ Активные загрузки, VAD, диаризация и долгие транскрипции защищены от выгрузки по простою — отсчёт времени начинается только после завершения обработки
- 🌍 Добавлены переводы для настройки неактивности модели на всех поддерживаемых языках

## Improved

- ⚡ Улучшено переиспользование моделей: Sona больше не перезагружает уже загруженную подходящую модель
- 🔄 Sona обновлена до v0.3.5: отслеживание родительского процесса на Windows и надёжная очистка дочерних процессов

## Fixed

- 🪟 Исправлено то, что Vibe и Sona оставались открытыми после выхода на Windows — это могло занимать память GPU и мешать повторному запуску
