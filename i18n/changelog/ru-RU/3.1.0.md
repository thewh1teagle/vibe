## New

- 🎨 Приложение полностью переработано вокруг одного экрана drop-to-transcribe с изменяемой и поисковой боковой панелью недавних
- ✍️ Переработано редактирование транскрипта: клик в любом месте строки ставит курсор точно туда, куда кликнули, Enter/Tab/стрелки переходят между строками, Escape отменяет изменения
- 🎧 Строка, которая сейчас звучит, подсвечивается во время воспроизведения, вид следует за ней, а клик по таймкоду запускает воспроизведение с этого момента
- 👀 Новые параметры отображения транскрипта — размер текста, тайминги, метки говорящих и направление текста
- 📂 Один выбор файлов теперь принимает файлы и папки вместе на macOS, а папки по-прежнему работают через перетаскивание везде
- ⌨️ Глобальный хоткей диктовки задаётся нажатием клавиш, с готовыми комбинациями для тех, что зарезервированы macOS
- 🔔 Опциональный режим «Keep running in the tray»: закрытие окна оставляет Vibe работать для глобальной диктовки, по умолчанию выключен (спасибо @eggie04)
- ⚙️ Настройки перенесены из хранилища браузера в редактируемый app_config.json — агенты и люди могут его читать и менять, а Vibe сразу подхватывает изменения
- 🔢 Каждое числовое поле в настройках стало степпером, который можно удерживать, вводить вручную или сбрасывать, со словами «Never» и «Auto» вместо чисел
- 🌍 Добавлены чешский (спасибо @feretCZ), болгарский и немецкий (спасибо @nimdassdev) языки; все 22 языка полностью переведены

## Improved

- 🤖 AI-сводки теперь запускаются из главного окна: автоматически после транскрипции, если включено, или по запросу из меню AI транскрипта, отображаются как markdown и сохраняются вместе с транскриптом
- 🔁 Повторная транскрипция из боковой панели теперь сначала спрашивает язык, модель и параметры
- 🆙 Ожидающее обновление теперь показывается на переключателе боковой панели вместо того, чтобы прятаться в меню

## Fixed

- 🔤 Исправлено то, что расширения в верхнем регистре игнорировались — папка с файлами .MP3 больше не выглядит пустой (спасибо @plmelancon)
- 🐛 Отчёты об ошибках внутри приложения теперь приходят с названием реальной ошибки вместо "App reports bug"
- ↔️ Исправления RTL по всему приложению: боковая панель остаётся слева окна, таймлайн плеера перетаскивается в правильную сторону, а хоткеи читаются слева направо
