## Improved

- 🔍 **Ошибки теперь показывают, что вывел движок** — когда Sona падает посреди транскрипции, диалог с ошибкой, логи и отчёт об ошибке теперь содержат его последние строки вместо голого «failed to read sona event line», поэтому такие проблемы, как описанная выше, можно распознать по отчёту

## Fixed

- 🛠️ **Транскрипция снова работает на старых драйверах видеокарт AMD** — после перехода на новый движок машины с драйвером AMD 2020 года (Vulkan 1.2, часто встречается на ноутбуках с Ryzen и графикой Radeon) падали при первой же отправке задания на GPU с ошибкой «vkQueueSubmit: Invalid queue». Драйвер возвращает пустой дескриптор очереди из `vkGetDeviceQueue2`; Sona 0.6.4 в этом случае откатывается на `vkGetDeviceQueue`, и GPU снова работает. Обновить драйвер AMD всё равно стоит, но это больше не обязательно
- 🖥️ **Старые процессоры Intel и AMD снова поддерживаются** — Vibe больше не отказывается распознавать речь на CPU без AVX2. Sona поставляет свой движок для CPU в двух вариантах — сборка AVX2 и базовая сборка AVX — и при запуске выбирает ту, которую способен выполнить ваш процессор. Теперь распознаёт речь любая машина x86-64 начиная с 2011 года; сообщение «Your CPU is not supported» исчезло
- 🎮 **Нехватка памяти GPU больше не обрывает выполнение** — если видеокарте не хватает памяти в середине файла, Vibe перезагружает модель на CPU, повторяет попытку для этого файла один раз и завершает остальную очередь на CPU. Эта модель запоминается как слишком большая для вашего GPU и с этого момента загружается на CPU. Спасибо @mikemikimike за отчёт и первую версию исправления (#1471, #1472)
