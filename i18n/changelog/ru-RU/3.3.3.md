## New

- 🧭 **Получить модели** — в `Настройки → Модели` появилась страница «Получить модели». Выберите язык своих записей, сначала увидите рекомендуемую модель, а любую модель можно установить одним кликом: загрузка проверяется, и модель готова к работе сразу после завершения. Для каждой модели указано, кто её создал
- ⚡ **Zipformer2 66M Hebrew** — новая небольшая и очень быстрая модель для иврита, 75 МБ. В нашем тесте она расшифровала час речи на иврите примерно за 30 секунд и использует гораздо меньше памяти, чем более крупные модели. Лучше всего подходит для аудио только на иврите
- 🌐 **Модели на сайте** — тот же список теперь есть страницей на сайте, со ссылкой, которая открывает любую модель прямо в Vibe: https://thewh1teagle.github.io/vibe/models
