## Fixed

- 🧩 **Нет Vulkan-рантайма — не беда** — на Windows-компьютере без загрузчика Vulkan (нет `vulkan-1.dll`, типично для машин без установленного драйвера GPU) движок транскрипции вообще не запускался. Теперь движок открывает загрузчик во время выполнения и просто работает на CPU, если его нет. Апстрим: ggml-org/ggml#1614
- 🎯 **Корректная транскрипция на видеокартах AMD со старыми драйверами** — на некоторых GPU AMD с драйвером Windows 2020 года (замечено на встроенной Radeon в ноутбуке с Ryzen) GPU выдавал бессмыслицу: одинокий «!» или случайные символы, тогда как CPU работал правильно. Драйвер оставляет GPU неклассифицированным в движке, из-за чего kernel внимания запрашивал ширину подгруппы, которую железо не может обеспечить. Sona 0.6.5 запрашивает её только там, где драйвер может это предоставить, и GPU снова распознаёт речь корректно, в несколько раз быстрее CPU. Исправление на уровне апстрима предложено в ggml (ggml-org/ggml#1619)
