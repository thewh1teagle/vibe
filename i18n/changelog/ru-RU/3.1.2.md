## New

- 🖥️ **Процессор без AVX2 теперь называется по имени** — вместо того чтобы падать без объяснений, Vibe сообщает, что процессор не поддерживается, и почему
- 🎙️ **Записи стали громче на 9 дБ** — подмешивание системного звука незаметно снижало уровень вдвое, а затем ещё раз вдвое. Каждая запись, сделанная с включённым системным звуком, была намного тише, чем должна была быть
- ⌨️ **Диктовка по умолчанию использует комбинацию из двух клавиш** — Option+Space на macOS, Ctrl+Space на остальных системах, вместо аккорда из трёх клавиш
- 🤖 **Установите навык для агента** — `Настройки → API и агенты` записывает его для Claude Code и Codex, чтобы он был доступен в каждой сессии, с уже встроенными папкой транскриптов и локальным API
- 🪟 **Windows: версия runtime VC++ теперь проверяется** — установщик раньше спрашивал только о том, есть ли *хоть какой-то* runtime, поэтому машины со старой версией пропускались и позже падали без какого-либо сообщения

## Improved

- ⚙️ **Настройки снова сохраняются** — в 3.1.1 каждая настройка сбрасывалась к значению по умолчанию после перезапуска. Файл на диске всегда был корректным — приложение просто никогда не считывало его обратно. Если вы уже опустили руки и перестали заново всё настраивать, теперь это в прошлом
- 🧠 **Вдвое меньше памяти на загрузку модели** — измерено 294 МБ → 216 МБ на маленькой модели, и примерно на одну копию модели меньше на больших. У машин, которым раньше не хватало памяти в середине загрузки, теперь есть запас

## Fixed

- 🔍 **Сбои теперь объясняют причину** — если сайдкар падает, теперь сообщается его код завершения и сигнал, а не голое «sona process died», а сбой посреди транскрипции читается как сбой, а не как «error decoding response body». Собственная диагностика Whisper снова попадает в лог — раньше её молча отбрасывал пустой callback
- 📦 **Повреждённые загрузки моделей теперь отлавливаются** — файлы проверяются перед использованием, незавершённые обнаруживаются при запуске и предлагается перезагрузить их заново, а прерванная загрузка больше не может выдавать себя за установленную модель
- 📱 **QR-код для сопряжения с телефоном сканируется** — один неверный символ в генераторе QR-кода смещал позиционные метки на любом коде выше определённого размера, а код сопряжения был как раз чуть больше этого предела. Ни один сканер не мог его прочитать
- 🔗 **yt-dlp перестал надоедать** — уведомление об обновлении появлялось при каждом запуске и забывало о нажатии «Later» каждый раз. Теперь это тост, который можно закрыть, показывается не чаще раза в неделю, и предлагает обновление, когда загрузка действительно завершается ошибкой — то есть именно тогда, когда это полезно
- 🌍 Название продукта и неверно переведённая настройка исправлены во всех 22 языках
