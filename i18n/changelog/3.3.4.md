## New

- ⚡ **Zipformer2 66M Slovak** — a new small and very fast Slovak model, 75 MB, by @neurlang. Install it from `Settings → Models`: open Get models and choose Slovak. Best for Slovak-only audio

## Fixed

- 🧱 **Processors without AVX** — transcription stopped with an illegal instruction error on processors that have no AVX, such as older Pentium and Celeron chips. Vibe now includes a build for them and picks it automatically. Expect it to be slow there; the small models are the best choice (#1731)
- 🪜 **Automatic step down** — if the transcription engine stops on an instruction the processor cannot run, Vibe now retries with the next simpler build until one works, and remembers it. `Settings → Advanced` has a new SSE4.2 choice to set it by hand
