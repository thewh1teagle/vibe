## New

- 📱 Vom Telefon aus aufnehmen: scannen Sie einmalig den QR-Code unter `Einstellungen → Telefon`, und Ihr Telefon kann Aufnahmen an diesen Computer senden — er transkribiert sie mit dem bereits geladenen Modell und schickt den Text direkt zurück
- 🏠 Die Telefonseite ist eine Web-App, die Sie zum Homescreen hinzufügen: nichts aus einem App Store zu installieren, kein Konto nötig, und sie funktioniert sowohl über Mobilfunk als auch über WLAN
- 🔒 Audio läuft über eine verschlüsselte Peer-to-Peer-Verbindung auf Basis von [iroh](https://www.iroh.computer/) — Telefon-Browser können kein Hole-Punching, daher läuft es über ein Relay, das nur je verschlüsselten Text sieht, nie Ihr Audio
- 💾 Telefon-Aufnahmen werden unter `Documents/Vibe` gespeichert und erscheinen unter „Zuletzt verwendet“ wie jedes andere Transkript, und eine Aufnahme wartet sicher auf dem Telefon, bis der Computer wieder erreichbar ist
- 🌍 Die Sprachauswahl auf dem Telefon richtet sich nach dem geladenen Modell, sodass sie immer genau das anbietet, was Ihr Desktop tatsächlich kann
- 🚀 Neue Einstellung „Beim Start starten“, standardmäßig aus, direkt neben „Im Hintergrund weiterlaufen“ — zusammen sorgen sie dafür, dass der Desktop erreichbar ist, wenn Sie zum Telefon greifen
- 🌐 Jeder neue Bildschirm ist in alle 22 Sprachen übersetzt
