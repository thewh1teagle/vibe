## New

- ⏳ **Ein Start, der zeigt, was passiert** — eine Transkription bleibt nicht mehr bei 0 % stehen, während sie sich vorbereitet. Sie nennt den aktuellen Schritt (Audio vorbereiten, Sprecher erkennen, Transkription starten), und bei einer langen Aufnahme weist sie darauf hin, dass die ersten Zeilen einige Minuten brauchen können

## Fixed

- 🔁 **Wiederholte Zeilen** — wenn Whisper beginnt, dieselbe Zeile immer wieder zu schreiben, wird dieser Abschnitt jetzt erneut versucht, statt übernommen zu werden. So endet eine lange Aufnahme deutlich seltener als ein einziger wiederholter Satz (#1023)
- ✍️ **Verschwindende Zeichensetzung** — die Standard-Temperatur ist jetzt 0 statt 0.4, wodurch Transkripte mitten im Text nicht mehr in Kleinschreibung ohne Zeichensetzung abgleiten. Wenn Sie die Einstellung nie geändert haben, wird sie für Sie aktualisiert; ein von Ihnen gewählter Wert bleibt erhalten
- ✂️ **Fehlende erste Wörter bei Parakeet und Nemotron** — das erste Wort eines Satzes wird nicht mehr verschluckt, und am Ende wird kein zusätzliches Wort angehängt
