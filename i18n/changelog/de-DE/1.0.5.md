## New

- Option zum Ziehen von Dateien ins Fenster hinzugefügt
- Option zum Öffnen einer Datei per Rechtsklick -> `Open with` hinzugefügt
- Animation beim Ablegen von Dateien
- Unterstützung für weitere Audioformate wie `opus` hinzugefügt (danke @renatoianhez für den Vorschlag)
- Option hinzugefügt, das App-Konfigurationsverzeichnis zu öffnen, um Protokolle zu erhalten
- Parameterinfos beim Hovern in den erweiterten Optionen hinzugefügt (danke @NHLOCAL)
- Schwedische Sprache hinzugefügt (danke @2bbe)
- Option zum Abbrechen des Modell-Downloads

## Improved

- UX verbessert, durch Ersetzen von onClick durch onMouseDown
- Standard-Fenstergröße verbessert
- Design des Einstellungsfensters verbessert
- Auf die neuesten tauri-Core/Plugins aktualisiert
- Offline-Installation verbessert

## Fixed

- Absturzprotokoll zum Panic-Hook hinzugefügt
- Fortschrittsanimation in der Taskleiste behoben
