## New

- 🛡️ Die Transkribieren-Schaltfläche wird deaktiviert, wenn kein Modell ausgewählt ist, mit einem hilfreichen Hinweis
- ⬇️ Der Link zum Herunterladen von Modellen wurde an den Anfang der Einstellungen verschoben, für leichteren Zugriff

## Improved

- 📋 Sona meldet beim Start jetzt Version und Commit-Hash

## Fixed

- 🔧 Absturz beim Laden von Modellen für Nutzer mit Nicht-ASCII-Benutzernamen unter Windows behoben
- 🖥️ Sanfter Rückfall auf die CPU, wenn Vulkan-GPU-Treiber fehlen
- 🔍 Bessere Fehlermeldungen, wenn Sona beim Laden eines Modells abstürzt
