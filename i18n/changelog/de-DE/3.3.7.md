## New

- ⬇️ **Update-Downloads im Hintergrund** — eine neue Version wird jetzt unbemerkt heruntergeladen, während Sie arbeiten, und wartet, bis Sie sie wollen. Die Installation ist ein Klick: Vibe aktualisiert sich, startet von selbst neu und macht dort weiter, wo Sie aufgehört haben, ganz ohne zweite Rückfrage. Es wird nie etwas installiert oder neu gestartet, ohne dass Sie es verlangen. Die Downloads lassen sich unter `Einstellungen → Allgemein` ausschalten
- 🔔 **Update-Erinnerung** — ein Update, das seit zwei Tagen wartet, zeigt in der App eine kleine Leiste mit Später und Zum Aktualisieren neu starten. Keine Pop-ups und keine Systembenachrichtigungen

## Fixed

- 🫥 **Versteckter Start** — wenn Vibe so eingestellt war, dass es beim Systemstart startet, konnte sein Fenster trotzdem erscheinen und den Fokus an sich ziehen. Es bleibt jetzt im Infobereich, bis Sie es öffnen
