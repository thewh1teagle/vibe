## New

- 🖥️ **Eine CPU ohne AVX2 wird benannt** — statt anonym abzustürzen, sagt Vibe jetzt, dass der Prozessor nicht unterstützt wird, und warum
- 🎙️ **Aufnahmen sind 9 dB lauter** — das Einmischen von Systemaudio halbierte den Pegel unbemerkt, und dann noch einmal. Jede mit ausgewähltem Systemaudio gemachte Aufnahme war deutlich leiser als sie sein sollte
- ⌨️ **Diktat verwendet standardmäßig ein Zwei-Tasten-Kürzel** — Option+Leertaste unter macOS, Strg+Leertaste sonst, statt eines Drei-Tasten-Kürzels
- 🤖 **Skill für den Agenten installieren** — `Einstellungen → API & Agenten` schreibt ihn für Claude Code und Codex, sodass er in jeder Sitzung verfügbar ist, mit dem Transkripte-Ordner und der lokalen API gleich eingebaut
- 🪟 **Windows: die VC++-Runtime wird versionsgeprüft** — der Installer fragte bisher nur, ob überhaupt irgendeine Runtime vorhanden war, sodass Rechner mit einer alten übersprungen wurden und später ohne Meldung abstürzten

## Improved

- ⚙️ **Ihre Einstellungen bleiben jetzt erhalten** — in 3.1.1 setzte sich jede Einstellung beim Neustart auf ihren Standardwert zurück. Die Datei auf der Festplatte war immer korrekt; die App las sie nur nie wieder ein. Wer es aufgegeben hat, seine Einstellungen neu zu setzen: sie sind jetzt sicher
- 🧠 **Halb so viel Speicher zum Laden eines Modells** — gemessen 294 MB → 216 MB bei einem kleinen Modell, und bei großen Modellen etwa eine Modellkopie weniger. Rechner, denen mitten im Laden der Speicher ausging, haben jetzt Platz

## Fixed

- 🔍 **Fehlschläge sagen jetzt, woran es lag** — ein Sidecar, der abstürzt, meldet jetzt seinen Exit-Code und sein Signal statt eines nackten "sona process died", und ein Absturz mitten in der Transkription liest sich als Absturz statt als "error decoding response body". Whispers eigene Diagnosemeldungen erreichen das Protokoll wieder, nachdem sie zuvor stillschweigend von einem wirkungslosen Callback verworfen wurden
- 📦 **Beschädigte Modell-Downloads werden erkannt** — Dateien werden vor der Nutzung geprüft, unvollständige werden beim Start erkannt und ein erneuter Download wird angeboten, und ein unterbrochener Download kann sich nicht mehr als installiertes Modell ausgeben
- 📱 **Der QR-Code für die Telefon-Kopplung lässt sich scannen** — ein falsches Zeichen im QR-Generator verschob die Ausrichtungsmuster bei jedem Code ab einer bestimmten Größe, und der Kopplungscode lag knapp darüber. Kein Scanner konnte ihn lesen
- 🔗 **yt-dlp hört auf zu nerven** — die Update-Meldung erschien bei jedem Start und vergaß "Später" jedes Mal. Sie ist jetzt ein wegwischbarer Hinweis, höchstens einmal pro Woche, und bietet das Update an, wenn ein Download tatsächlich fehlschlägt — genau dann, wenn es hilft
- 🌍 Der Produktname und eine falsch übersetzte Einstellung wurden in allen 22 Sprachen korrigiert
