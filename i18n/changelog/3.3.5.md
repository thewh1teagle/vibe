## Fixed

- 🔊 **Audio playback on Linux** — the play button did nothing on Linux, so you could not listen to a recording while reviewing its transcript. The Linux packages now include what the system's media player needs to open the file (#1711)
- 📦 **Installing on Fedora** — after installing the RPM, Vibe could fail to start with a missing `libxdo.so.3` error. The package now asks the system to install that library with it (#1124)
