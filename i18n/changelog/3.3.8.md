## New

- 🦜 **More Parakeet models** — any Parakeet TDT model in GGUF format now loads, not only the ones named v3, so fine-tunes from other publishers work. A model built for a different audio format is refused with a clear message instead of failing later. Orukeet 0.6B, a Parakeet v3 fine-tune for 25 European languages, is available in `Get models` (#1577, #1753) — thanks @Nathan-Roll1
- ⬇️ **Background update downloads** — a new version is now downloaded quietly while you work and waits until you want it. Installing is one click: Vibe updates, restarts by itself and comes back where you left it, with no second question. Nothing is ever installed or restarted unless you ask. You can turn the downloads off in `Settings → General`
- 🔔 **Update reminder** — an update that has been waiting for two days shows a small bar inside the app with Later and Restart to update. No pop-ups and no system notifications

## Improved

- 🔒 **Safer downloads** — models from the catalog and the yt-dlp helper are now checked against a published checksum before they are used, and model downloads only run over HTTPS. A `vibe://download` link to a model that is not in the catalog shows the full address with a warning, and is no longer selected automatically (#1741)
- 🧹 **Temporary files** — recordings and downloads in progress now live in a private folder of Vibe's own rather than the shared system temp folder, are removed as soon as they are saved to a project, and anything left over is cleared after a day (#1741, #841)
- 🕶️ **Analytics** — error reports no longer include file names or folder paths, and turning analytics off now also discards anything that was waiting to be sent. Setting `DO_NOT_TRACK=1` turns analytics off as well (#1741)
- 🎙️ **Missing microphone** — if the microphone or speaker you chose is unplugged, Vibe records from the system default and tells you, and your choice comes back when the device does. A recording that captured no sound at all now shows a warning (#1676)

## Fixed

- 🎬 **Files that could not be converted** — when a video or audio file could not be read, the error showed ffmpeg's version details instead of the reason. It now shows what went wrong with the file (#1752)
- 🐘 **Very large files** — transcribing a multi-gigabyte video could crash with an out-of-memory error, because the whole file was held in memory. Files are now read from disk as they go (#1557)
- 📱 **Phone recording on iPhone and Safari** — pairing timed out on every iPhone and in Safari. The phone page now connects correctly; no desktop update is needed for this one (#1566)
- 🎚️ **Recording from the wrong device** — the saved microphone was remembered by its position in the device list, so after plugging in headphones or a virtual audio device Vibe could silently record from another one, or fail with "Failed to get device by ID" (#1676)
- 💥 **Crashes on some Windows graphics cards** — a graphics driver error during transcription closed the engine with "Rust cannot catch foreign exceptions". These errors are now handled, and Vibe retries the file on the CPU (#1250)
- 🛑 **Cancel and New transcription** — cancelling one transcription could stop others that were running, and pressing New transcription discarded the one in progress. Cancel now stops only the job you cancelled, and new files queue behind the running one (#1484, #1477)
- 🎬 **"Access is denied" on Windows** — if a folder named `ffmpeg` was on the system PATH, every transcription failed with "invalid audio file: Access is denied". Vibe now uses its own bundled ffmpeg first (#1668)
- 🔗 **Pasted links** — text pasted into the link box that is not a web address is left in the box instead of being passed to the downloader (#1741)
- 🖼️ **Export preview** — the preview now follows the Light or Dark choice in every format, including JSON and plain text
- 🫥 **Starting hidden** — when Vibe was set to launch at startup, its window could still appear and take focus. It now stays in the tray until you open it
