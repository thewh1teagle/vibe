## New

- 🖥️ **不支援 AVX2 的 CPU 會被具體列明** — Vibe 現在不會默默當機,而是會說明處理器不受支援,以及原因
- 🎙️ **錄音音量提升 9 dB** — 混入系統音訊時,音量一直被靜靜地減半,然後再減半一次。所有選用系統音訊錄製的錄音,音量都比應有的低得多
- ⌨️ **聽寫預設改為雙鍵快速鍵** — macOS 用 Option+Space,其他系統用 Ctrl+Space,取代原本的三鍵組合
- 🤖 **安裝 agent skill** — `設定 → API 與 AI 代理` 會把它寫入 Claude Code 和 Codex,使其在每個工作階段都可用,並內建逐字稿資料夾和本機 API
- 🪟 **Windows:VC++ 執行階段現在會檢查版本** — 安裝程式以往只檢查*是否*已安裝任何版本的執行階段,結果安裝了舊版本的機器會被略過,之後才無聲無息地當機

## Improved

- ⚙️ **設定不再失效** — 在 3.1.1 中,所有設定重啟後都會回復預設值。磁碟上的檔案其實一直是正確的,只是應用程式從來沒有把它讀回來。如果你已經放棄重新設定自己的偏好,現在可以放心了
- 🧠 **載入模型所需的記憶體減半** — 在小型模型上實測由 294 MB 減至 216 MB,大型模型上大約減少一份模型副本的用量。以往在載入途中就會記憶體不足的機器,現在有了空間

## Fixed

- 🔍 **錯誤現在會說明原因** — 子進程當機時,現在會回報結束代碼和訊號,而不再只是一句「sona process died」;轉錄途中的當機亦會如實顯示為當機,而不是「error decoding response body」。Whisper 本身的診斷訊息現在也能再次寫入日誌,以往被一個無效的回呼靜靜地丟棄了
- 📦 **損壞的模型下載現已能被偵測** — 檔案使用前會先被驗證,啟動時會偵測不完整的檔案並提供重新下載,中斷的下載也不能再被誤認為已安裝的模型
- 📱 **手機配對的 QR code 可以掃描了** — QR code 產生器中一個錯誤的字元,令超過某個大小的 code 定位圖案錯位,而配對用的 code 剛好超過這個大小。以往沒有任何掃描器讀得到
- 🔗 **yt-dlp 不再煩人地提示更新** — 更新提示以往每次啟動都會出現,並且每次都會忘記你按過「稍後再說」。現在改為每星期最多出現一次的可關閉提示,並且只在下載真的失敗時才提示更新,因為那才是真正有用的時機
- 🌍 全數 22 種語言中的產品名稱和一項翻譯錯誤的設定已修正
