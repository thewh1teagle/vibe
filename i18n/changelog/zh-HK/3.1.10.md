## Fixed

- 🧩 **沒有 Vulkan runtime 也沒問題** — 沒有安裝 Vulkan loader 的 Windows 電腦(缺少 `vulkan-1.dll`,常見於完全沒有安裝顯示卡驅動的機器)以往完全無法啟動轉錄引擎。引擎現在會在執行時嘗試開啟 loader,找不到就直接改用 CPU 運行。上游:ggml-org/ggml#1614
- 🎯 **在較舊驅動程式的 AMD 顯示卡上正確轉錄** — 部分執行 2020 年版 Windows 驅動程式的 AMD 顯示卡(在 Ryzen 筆電的 Radeon 內顯上發現)會輸出亂碼:單獨一個「!」或隨機字元,而 CPU 的輸出卻是正確的。驅動程式在引擎中把該 GPU 標示為未分類,導致注意力核心要求一個硬件無法支援的 subgroup width。Sona 0.6.5 只會在驅動程式能夠支援的情況下才要求該寬度,GPU 現在可以再次正確轉錄,速度比 CPU 快數倍。上游修正已提交至 ggml (ggml-org/ggml#1619)
