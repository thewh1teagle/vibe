## New

- 🦜 **更多 Parakeet 模型** — 現在可以載入任何 GGUF 格式的 Parakeet TDT 模型,不再限於名稱為 v3 的模型,因此其他發佈者的微調模型也能使用。為其他音訊格式而建的模型會被拒絕並顯示清楚的訊息,而不是稍後才失敗。Orukeet 0.6B 是支援 25 種歐洲語言的 Parakeet v3 微調模型,可在 `取得模型` 中取得 (#1577, #1753) — 感謝 @Nathan-Roll1
- ⬇️ **背景下載更新** — 新版本現在會在你工作時靜靜地下載,並等你需要時才安裝。只需一按即可安裝:Vibe 會自行更新、重新啟動,並回到你離開時的位置,不會再問第二次。除非你要求,否則不會安裝或重新啟動任何東西。你可以在 `設定 → 一般` 關閉下載功能
- 🔔 **更新提醒** — 如果有更新已等候兩天,應用程式內會顯示一條小橫幅,附有「稍後更新」和「重新啟動以更新」。不會有彈出視窗,也不會有系統通知

## Improved

- 🔒 **更安全的下載** — 目錄中的模型和 yt-dlp 輔助程式在使用前,現在會先對照已公布的校驗碼進行檢查,而且模型只會透過 HTTPS 下載。指向目錄以外模型的 `vibe://download` 連結會顯示完整網址並附上警告,亦不再自動選取 (#1741)
- 🧹 **暫存檔案** — 進行中的錄音和下載現在存放在 Vibe 專用的私人資料夾,而不是系統共用的暫存資料夾;儲存到專案後會立即移除,殘留的檔案會在一天後清除 (#1741, #841)
- 🕶️ **匿名使用統計** — 錯誤報告不再包含檔案名稱或資料夾路徑,而且關閉匿名使用統計後,亦會丟棄所有等待傳送的資料。設定 `DO_NOT_TRACK=1` 同樣會關閉匿名使用統計 (#1741)
- 🎙️ **找不到麥克風** — 如果你選擇的麥克風或揚聲器已被拔出,Vibe 會改用系統預設裝置錄音並通知你,裝置重新接上後會恢復使用你的選擇。完全沒有錄到聲音的錄音,現在會顯示警告 (#1676)

## Fixed

- 🎬 **無法轉換的檔案** — 影片或音訊檔案無法讀取時,錯誤訊息顯示的是 ffmpeg 的版本資料,而不是原因。現在會顯示檔案出了什麼問題 (#1752)
- 🐘 **非常大的檔案** — 轉錄數 GB 的影片時可能會因記憶體不足而當機,原因是整個檔案都被載入記憶體。現在會一邊讀取、一邊從磁碟載入檔案 (#1557)
- 📱 **在 iPhone 和 Safari 上用手機錄音** — 每部 iPhone 以及在 Safari 中配對都會逾時。手機頁面現在可以正確連線,這項修正無需更新桌面版 (#1566)
- 🎚️ **用錯裝置錄音** — 已儲存的麥克風是按其在裝置清單中的位置記錄的,因此接上耳機或虛擬音訊裝置後,Vibe 可能會在無提示下改用另一個裝置錄音,或出現 "Failed to get device by ID" 錯誤 (#1676)
- 💥 **部分 Windows 顯示卡當機** — 轉錄期間的顯示卡驅動程式錯誤會令引擎關閉,並出現 "Rust cannot catch foreign exceptions"。現在這些錯誤已獲處理,Vibe 會改用 CPU 重試該檔案 (#1250)
- 🛑 **取消與新增轉錄** — 取消一項轉錄可能會停止其他正在執行的轉錄,而按下「新增轉錄」會捨棄進行中的那一項。現在「取消」只會停止你取消的那項工作,新檔案會排在執行中的工作之後 (#1484, #1477)
- 🎬 **Windows 上的 "Access is denied"** — 如果系統 PATH 中有名為 `ffmpeg` 的資料夾,每次轉錄都會失敗並出現 "invalid audio file: Access is denied"。現在 Vibe 會優先使用自己內含的 ffmpeg (#1668)
- 🔗 **貼上的連結** — 貼到連結欄的文字如果不是網址,會保留在欄內,而不會交給下載程式處理 (#1741)
- 🖼️ **匯出預覽** — 預覽現在會在所有格式(包括 JSON 和純文字)中跟隨「淺色」或「深色」的選擇
- 🫥 **隱藏啟動** — 當 Vibe 設定為開機時啟動,視窗仍可能出現並取得焦點。現在它會留在系統匣,直到你自行開啟
