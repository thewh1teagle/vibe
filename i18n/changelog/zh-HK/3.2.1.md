## New

- 🧮 **CPU 指令集** — 設定 → 進階設定 → 處理器 可以為引擎的 CPU 版本選擇 Automatic、AVX2 或 Baseline (AVX)。Automatic 會跟從處理器所支援的指令集；如果轉錄曾經因為非法指令而中斷，就應該選 Baseline

## Fixed

- 💥 **舊款 Intel Mac 出現非法指令錯誤** — Intel macOS 引擎一直是針對建置該引擎的機器的 CPU 編譯的,所以任何早於 Haswell(2013 年)的 Intel Mac,一載入模型就會當機。Intel macOS 現在和 Linux、Windows 一樣,會提供兩個 CPU 版本,並在啟動時自動選擇合適的一個。萬一選錯了,Vibe 會自行以 baseline 版本重新啟動引擎,並記住這個選擇。感謝 @I-G-1-1 提供報告和 sysctl 輸出 (#1499)
- 🔍 **錯誤報告中的 AVX2 資訊** — 在 Intel Mac 上以往一直顯示 `true`,現在已改為真正的檢測結果
