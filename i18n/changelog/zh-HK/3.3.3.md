## New

- 🧭 **取得模型** — `設定 → 模型` 新增「取得模型」頁面。選擇錄音的語言,即可先看到建議的模型,並一鍵安裝任何模型:下載內容會經過驗證,完成後即可使用。每個模型都會顯示製作者
- ⚡ **Zipformer2 66M Hebrew** — 全新的小型超快希伯來語模型,75 MB。在我們的測試中,一小時的希伯來語音訊約 30 秒就轉錄完成,而且記憶體用量遠低於較大的模型。最適合純希伯來語音訊
- 🌐 **網站上的模型** — 同一份清單現在也是網站上的一個頁面,並提供連結,可直接在 Vibe 中開啟任何模型:https://thewh1teagle.github.io/vibe/models

## Fixed

- 🧩 **句子黏在一起** — Parakeet 和 Nemotron 的純文字結果會把句子連在一起,中間沒有空格
