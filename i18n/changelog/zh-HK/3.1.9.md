## Improved

- 🔍 **錯誤訊息現在會顯示引擎的輸出內容** — 當 Sona 在轉錄途中當機,錯誤對話框、日誌和錯誤報告現在會附上它最後輸出的內容,而不是單單一句「failed to read sona event line」,所以像上面那類問題現在可以從報告中辨識出來

## Fixed

- 🛠️ **較舊的 AMD 顯示驅動程式再次可以轉錄** — 自從換用新引擎後,使用 2020 年版 AMD 驅動程式(Vulkan 1.2,常見於配備 Radeon 顯示卡的 Ryzen 筆電)的機器,一到第一次提交 GPU 工作就會出現「vkQueueSubmit: Invalid queue」並當機。該驅動程式從 `vkGetDeviceQueue2` 回傳空的 queue handle;Sona 0.6.4 現在會改用 `vkGetDeviceQueue` 作為後備,GPU 因此再次可用。更新 AMD 驅動程式仍然是個好主意,但已不再是必要
- 🖥️ **較舊的 Intel 和 AMD CPU 再次可用** — Vibe 不再拒絕在沒有 AVX2 的 CPU 上轉錄。Sona 現在提供兩個 CPU 引擎版本,AVX2 版本和 AVX baseline 版本,啟動時會自動選擇處理器能運行的一個。任何 2011 年後推出的 x86-64 機器現在都可以轉錄;「Your CPU is not supported」的訊息已經消失
- 🎮 **顯示卡記憶體不足不會再令整個工作中斷** — 當顯示卡在處理檔案途中記憶體不足,Vibe 會把模型重新載入到 CPU,重試該檔案一次,並在 CPU 上完成佇列中其餘的檔案。該模型會被記住對這張顯示卡來說太大,之後都會直接載入到 CPU。感謝 @mikemikimike 提供報告和初步修正 (#1471, #1472)
