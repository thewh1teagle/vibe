## New

- 🧠 新增了一項進階設定,可自動卸載閒置的轉錄模型並釋放 RAM/VRAM;設為 0 即保持模型常駐載入
- ⏱️ 保護正在進行的上傳、VAD、講者辨識和長篇轉錄不受閒置卸載影響——逾時計時只會在處理完成後才開始
- 🌍 為模型閒置設定新增了所有支援語言的翻譯

## Improved

- ⚡ 改善了模型重用機制,Sona 現在會跳過重新載入已載入的相同模型
- 🔄 Sona 更新至 v0.3.5,加入了 Windows 父程序監控和可靠的子程序清理機制

## Fixed

- 🪟 修正了 Vibe 和 Sona 在 Windows 上結束後仍未關閉的問題,以往可能會佔用 GPU 記憶體並阻止重新啟動
