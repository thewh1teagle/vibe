## New

- 🧭 **モデルを入手** — `設定 → モデル` に新しい「モデルを入手」ページが加わりました。録音の言語を選ぶと、おすすめのモデルが最初に表示され、どのモデルもワンクリックでインストールできます。ダウンロードは検証され、完了すればすぐに使えます。各モデルには作成元も表示されます
- ⚡ **Zipformer2 66M Hebrew** — 小さくてとても高速な新しいヘブライ語モデルです (75 MB)。テストでは1時間のヘブライ語を約30秒で文字起こしし、大きなモデルよりメモリ使用量がはるかに少なく済みます。ヘブライ語だけの音声に最適です
- 🌐 **ウェブサイトでモデル一覧** — 同じ一覧がウェブサイトのページになり、任意のモデルをVibeで直接開くリンクも付いています: https://thewh1teagle.github.io/vibe/models

## Fixed

- 🧩 **文がつながってしまう問題** — ParakeetとNemotronのプレーンテキスト結果で、文と文のあいだにスペースが入らずつながっていました
