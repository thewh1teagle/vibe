## New

- ✨ **AI Assistant** — Settings → AI Assistant sets the connection once (Ollama, OpenAI-compatible, or Claude) with a Test button that says in one line whether the key and server work. Summaries and dictation clean-up are now separate tasks, each with its own switch, presets, and prompt page, so tuning your meeting-notes prompt never changes what dictation does to a sentence
- 💬 **Ask about this transcript** — a box under the summary answers questions from the transcript itself ("What was decided about the budget?"), streams the answer, and keeps the thread in the project so it is still there next month
- 🧩 **Prompt presets and placeholders** — start from Summary, Meeting notes, TL;DR, Translate, or Rewrite as article, and use `{transcript}`, `{language}`, and `{speakers}` in your own prompt. Dictation has Punctuation only, Formal, and Casual, with a Try it box to see what a sentence becomes before trusting it with real words

## Improved

- 🌊 **Summaries stream in** — the text appears as the model writes it, and the Summary tab opens itself when a summary starts
- 📚 **Long recordings** — a transcript too long for the model's context is summarized in parts and then as a whole, with a part counter, instead of being cut off
- 🎙️ **Dictation clean-up** — runs its own prompt, and if the model fails the raw words are still typed or copied

## Fixed

- 🔁 **Dictation ran the summary prompt** — dictated text used to be sent through whatever the summary prompt said, which turned a sentence into meeting notes. Each task now has its own prompt
- 🔑 **Settings carry over** — the old AI settings (key, model, prompt) are migrated on first launch; nothing needs to be entered again
