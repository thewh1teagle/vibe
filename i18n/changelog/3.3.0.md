## New

- 🧪 **Beta updates** — turn on Settings → General → Beta updates to get each new version a few days before everyone else, so problems are caught before they reach most people. Turning it on checks for an update right away; turning it off keeps the version you have until the stable release catches up (#1677)

## Improved

- 📶 **Update progress** — the bar in the update dialog moves steadily instead of jumping, and no longer slides back to empty as the dialog closes
- 🇮🇱 **Hebrew Parakeet in the models docs** — the Hebrew Parakeet TDT model is listed on the Models page (#1624)
