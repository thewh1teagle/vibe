## New

- 🧮 **Jeu d'instructions du CPU** — Paramètres → Avancé → Processeur permet de choisir Automatique, AVX2 ou Base (AVX) pour la version CPU du moteur. Automatique suit ce que le processeur prend en charge ; Base est celle à choisir si la transcription plante avec une instruction illégale

## Fixed

- 💥 **Instruction illégale sur les anciens Mac Intel** — le moteur macOS Intel était compilé pour le CPU de la machine qui l'avait construit, si bien qu'un Mac Intel antérieur à Haswell (2013) plantait dès le chargement du modèle. macOS Intel propose désormais les deux mêmes versions CPU que Linux et Windows, et choisit la bonne au démarrage. Si le choix se révèle mauvais, Vibe relance le moteur sur la version de base tout seul et s'en souvient. Merci à @I-G-1-1 pour le signalement et la sortie de sysctl (#1499)
- 🔍 **Ligne AVX2 dans les rapports de bug** — sur les Mac Intel elle était toujours à `true` ; c'est désormais une vraie vérification
