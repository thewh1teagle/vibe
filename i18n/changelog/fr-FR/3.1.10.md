## Fixed

- 🧩 **Pas de runtime Vulkan, pas de problème** — un PC Windows sans loader Vulkan (pas de `vulkan-1.dll`, typique des machines sans pilote GPU installé) ne pouvait pas du tout démarrer le moteur de transcription. Le moteur ouvre désormais le loader à l'exécution et fonctionne simplement sur le CPU quand il n'y en a pas. En amont : ggml-org/ggml#1614
- 🎯 **Transcriptions correctes sur les cartes graphiques AMD avec des pilotes anciens** — sur certains GPU AMD utilisant un pilote Windows datant de 2020 (constaté sur le GPU intégré Radeon d'un ordinateur portable Ryzen), le GPU produisait n'importe quoi : un simple « ! » ou des caractères aléatoires, alors que le CPU était correct. Le pilote laisse le GPU non classé dans le moteur, et le kernel d'attention demandait alors une largeur de sous-groupe que le matériel ne peut pas exécuter. Sona 0.6.5 ne la demande que là où le pilote peut l'accorder, et le GPU transcrit à nouveau correctement, plusieurs fois plus vite que le CPU. Correctif proposé en amont à ggml (ggml-org/ggml#1619)
