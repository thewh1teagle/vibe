## New

- ⏳ **A start that tells you what is happening** — a transcription no longer sits at 0% while it gets ready. It names the step it is on (preparing the audio, recognizing speakers, starting transcription), and on a long recording it says the first lines can take a few minutes

## Fixed

- 🔁 **Repeated lines** — when Whisper starts writing the same line over and over, that part is now tried again instead of being kept, so a long recording is much less likely to end up as one repeated sentence (#1023)
- ✍️ **Punctuation that disappears** — the default temperature is now 0 instead of 0.4, which stops transcripts from drifting into lowercase text without punctuation partway through. If you never changed the setting it is updated for you; a value you chose is kept
- ✂️ **Missing first words with Parakeet and Nemotron** — the first word of a sentence is no longer dropped, and no extra word is added at the end
