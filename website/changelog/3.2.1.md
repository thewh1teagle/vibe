## New

- 🧮 **CPU instruction set** — Settings → Advanced → Processor lets you pick Automatic, AVX2, or Baseline (AVX) for the engine's CPU build. Automatic follows what the processor reports; Baseline is for a machine that advertises AVX2 it cannot run

## Fixed

- 💥 **Illegal instruction while loading the model** — a Hackintosh with spoofed CPUID reports AVX2 on a processor that has only AVX, so the engine picked the AVX2 build and died at once. Vibe now relaunches the engine on the baseline build after such a crash and keeps that choice, so transcription works without touching a setting. Thanks to @I-G-1-1 for the report (#1499)
